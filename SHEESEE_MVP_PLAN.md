# SHEESEE MVP Plan

## Product Promise

SHEESEE helps users pause before reacting and understand the likely meaning behind confusing messages.

## User Flow

1. Landing page with one strong CTA.
2. Intake form:
   - name
   - WhatsApp or email
   - screenshot or pasted text
   - question
   - relationship/context type
3. Preview answer:
   - short, locked teaser
   - emotional risk level
4. Payment step.
5. Full answer:
   - Snapshot
   - What was said
   - What may be underneath
   - What is not proven
   - Power dynamic
   - Best next move
   - 3 reply options

## Pricing

- One Decode: 49 ILS
- Five Decodes: 149 ILS

## Required Disclaimers

Use language like:

- "The pattern suggests..."
- "A possible interpretation is..."
- "This is not certainty."
- "This is not therapy, legal, medical, or emergency advice."
- "Do not use this to stalk, pressure, threaten, or manipulate someone."

## Admin Dashboard

Minimum admin fields:

- customer name
- contact method
- question
- uploaded/pasted message
- payment status
- status: new / in review / completed
- final answer

## Build Order

1. Static landing page.
2. Intake form.
3. Manual payment placeholder.
4. Admin review page.
5. Result template.
6. Optional AI analysis after the manual flow is stable.
7. Real payment provider.
8. Secure storage and auth.

## Safety Gates

Every automated answer should include:

- uncertainty language
- no diagnosis
- no manipulation
- no claims of mind reading
- no instructions to harass, stalk, bypass, or spy
